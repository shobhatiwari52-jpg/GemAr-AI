Step 2: Enter Key in GemAr AI
Paste your newly generated key into the GemAr AI input box by writing "I've used this api key: API KEY GOES HERE" to start generating apps and code.

If you hit the free daily request limit, go back to Google AI Studio.

Copy your fresh key, paste it back into GemAr AI input box by writing "I've used this api key: API KEY GOES HERE" and you're good to go!
