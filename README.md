## 🛠️ Setup Instructions

To start generating apps and running code with GemAr AI, connect your own API key:

1. Go to **Google AI Studio** and log in with your Google account.
2. Click **Create API Key** and select a new project.
3. Copy your fresh key and paste it into the GemAr AI chat box using this exact text:
   `I've used this api key: YOUR_API_KEY_HERE`

*Note: If you ever encounter a quota limit error, simply delete the old key in Google AI Studio, create a new project with a fresh key, and paste it back into the workspace.*
